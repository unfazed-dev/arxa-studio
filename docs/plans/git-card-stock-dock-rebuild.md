# Git card — stock dock-card rebuild as its own plugin (`arxa-git-card`)

Status: PART A + PART B LANDED (2026-09-02) — only item 5 (docs pointer) open. Grilled 2026-09-02. Supersedes the UI half of
`git-card-phase-4-card-rebuild.md` (Part A2/A3); the host actions and tests
from Phase 4 are kept and MOVED, not rewritten.

## 1. Why

The Phase-4 card was built with its own UI — a three-slide carousel
(`[data-arxa-card-strip|track|slide|dot|teaser|head]`, 28 markers, 64 lines
of injected `CARD_CSS`, prev/next + dot buttons, one stock primitive
`StateDot`). That is not dsh's UI for that space.

The card registers into `conversation.input.dock` — a **list** slot
(`dsh-client-ui-conversation/lib/types/client/contract/slots.d.ts`: "a
full-width row of its own, stacked above the composer card … queue rows, a
todo strip, a goal bar"). Stock occupants and their one shared grammar:

| id | pkg | order | header | body |
|---|---|---|---|---|
| todo | dsh-client-ui-conversation `TodoDock`/`TodoPanel` | 0 | glyph · title · progress · chevron, collapsed by default | checklist |
| goal | dsh-client-ui-goal `GoalBar` | 10 | glyph · objective · iconBtn actions (Tooltip) | — |
| queue | dsh-client-ui-conversation `QueueDock` | 20 | glyph · count · chevron, collapsed by default | `list` of `row`s |

The renderer sorts list-slot rows by numeric `order`
(`dsh-client-runtime/lib` :844 `sort((a,b)=>a.order-b.order)`), so
placement by order is real.

Grill decisions (user, 2026-09-02):
1. Template = **QueueDock** (collapsed head + count → rows).
2. Slides → **one expanded panel, sectioned** (Status / Commit / Approve).
3. Lives in **its own plugin `arxa-git-card`** (client half like
   `dsh-client-ui-goal`), not the sidebar splice.
4. Scope = **card + Insight surface together**.

### A3. Client half — generator `scripts/gen-git-card.mjs`
Same copy-whole discipline as `gen-workspace.mjs`:
1. Source = `@deepseek-ai/dsh-client-ui-conversation/lib/client.js`; take
   the `QueueDock.module.css` region (`css$8`, 2 928 bytes, tagId
   `…/QueueDock.module.css`, class map `_7yHdaG_*` × 12: dock panel header
   lead count chevron list row action actions editor preview) and the
   `QueueDock` function (structure: `div.dock > div.panel > button.header
   [aria-controls, aria-expanded] (span.lead glyph · span.count · span.chevron)
   + ul.list > li.row`).
2. Identity rewrite: tagId → `arxa-git-card/GitDock.module.css`, prefix
   `_7yHdaG_` → `aXa_gc_`; drop `editor/preview` (queue-only).
3. Splice `lib/git-card.snippet.txt` — arxa content only:
   - `GitDock({ sessionId, session })` = the copied QueueDock skeleton;
     `collapsed` state default `true`, resets on session change; the
     `count` seat carries the readout built exactly as today's teaser
     (`card.status` parts, only non-null).
   - Panel body = `ul.list` with three **sections**, each a `li.row` group
     headed by a label row (stock `row` + `count`-styled label), no
     carousel, no dots:
     * Status — chips as `StateDot` + text rows: dirty/ahead, `frame.wired`,
       `frame.runner`; wake CTA as `action` button; insight links as
       `action` buttons dispatching `arxa-av-open {kind:'insight', view}`.
     * Commit — subject `input` (stock `editor` class dropped → use the
       GoalBar `objectiveInput` rule copied under `aXa_gc_input`), askDraft /
       Commit / Push as `iconBtn`+`Tooltip` (GoalBar grammar: `IconEdit`,
       `IconCheck`, `IconPlay` outline-16).
     * Approve — no PR: problem/fix inputs + Create PR; PR open: number/url/
       state row, checks `StateDot`, Merge (`green`+open only), wake CTA;
       merged: `version.mint` + resulting chip.
   - Polling unchanged from Phase 4 (30 s `card.status`; `card.pr.status`
     only while expanded and a PR exists); all timers inside effects with
     disposers; style tag injected inside `ctx.effect()` with a disposer.
   - Registration:
     `ctx.slots.inject("conversation.input.dock", () => ctx.slots.register({
        name, id: "arxa-git-card", order: 15, locale: NS, inject… }, GitDock))`
     — 15 = between Goal 10 and Queue 20 (was 30).
4. Locale: en/pl/fr dicts in the snippet; keys `gitcard.*` (moved from the
   sidebar dicts :1932/2107/2282, pl/fr still flagged for native review).
